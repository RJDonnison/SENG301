# Composition

Composition is a design principle where a class is built from one or more existing classes by containing instances of them as members ("has-a" relationship), rather than inheriting from them.

## When to use

- When you need flexible runtime behavior that can change dynamically
- To favor loose coupling over rigid class hierarchies
- When a "has-a" relationship is more natural than an "is-a" relationship
- To reuse behavior across unrelated classes without forcing them into a shared hierarchy
